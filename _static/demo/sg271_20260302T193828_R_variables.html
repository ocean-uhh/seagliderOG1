(A) Glossary

renamed
In the file under its OG1 name; original_name holds the basestation name.
passthrough
In the file under its basestation name.
consumed
Not in the file itself; its data went into a variable the converter built.
skipped
Not in the file; its dimension is not placed on N_MEASUREMENTS.
derived
Built by the converter; its inputs are listed.
shared axis (N_MEASUREMENTS)
The one time axis of the OG1 file. Every basestation dimension (CTD samples, engineering samples, guidance-and-control events, GPS fixes, each sensor's samples) is placed on it by time, so most variables are empty at most data points.
numbered copy (_2, _3)
When two basestation variables map to one OG1 name, the first (CTD first, then non-QC, then input order) keeps it and the next becomes NAME_2.
per-dive scalar
A basestation parameter whose value changes between dives, written as JSON text {"dives": [...], "values": [...]}.
loss
Something in the basestation files that is not in the OG1 file in the same form: dropped structure, or a label (a unit spelling, an attribute) not kept.
step
A recorded change that keeps the information: a unit factor (stored in original_units), units relabelled, a float64 value stored as float32.
inputs not recorded
The conversion did not record which basestation variables this one was built from; the page says so instead of guessing.
