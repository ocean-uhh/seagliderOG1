Example report

The HTML conversion report for the bundled sg271 sample — the page seagliderOG1 process --report writes beside each OG1 file. It checks the configuration against the data, lists the OG1 variables present and absent, names each basestation variable’s fate, and shows the scalar parameters and global attributes. This one is the sg271 Drygalski Trough sample (three dives, see Demo: the sg271 sample), rebuilt on every docs build.

To make it yourself, from any directory:

seagliderOG1 init --example        # writes sg271.yaml pointing at the packaged dives
seagliderOG1 process sg271.yaml    # writes the OG1 file and this page beside it
