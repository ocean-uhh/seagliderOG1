Example report

Open the example report — the pages seagliderOG1 process --report writes beside the OG1 file for the bundled sg271 sample (Drygalski Trough, three dives; see Demo: the sg271 sample), rebuilt on every docs build. It opens on the Conversion page; the nav at the top of each page reaches the others.

  • Conversion — the summary: what went in, what came out, what was lost, and anything to check in mission.yaml.

  • Variables — every variable, basestation input beside OG1 output, searchable and filterable.

  • Processing — every step of the conversion, in the order it ran.

  • Phase — how PHASE was assigned.

  • Basestation — the dive files as read, across the mission.

  • OG1 format — the OG1 file: conformance and inventory.

What each page shows is in The report pages. To make the report yourself, from any directory:

seagliderOG1 init --example        # writes sg271.yaml pointing at the packaged dives
seagliderOG1 process sg271.yaml    # writes the OG1 file and the report pages beside it
