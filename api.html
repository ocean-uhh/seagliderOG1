API reference

The public API is a set of verbs on the top-level package:

  • seagliderOG1.read — read a mission’s basestation files into a list of datasets.

  • seagliderOG1.convert — convert that list into one OG1 dataset.

  • seagliderOG1.write — write the OG1 dataset to netCDF.

  • seagliderOG1.report — write the HTML conversion page for a written file.

  • seagliderOG1.enrich — set global attributes on a written file, in place.

  • seagliderOG1.process — load a mission configuration and run read + convert + write (and optionally the page) for one mission.

  • seagliderOG1.process_missions — the same across a root of several missions.

  • seagliderOG1.mission — load and check a mission.yaml (mission.load / mission.check).

plus the exceptions seagliderOG1.MissionError and seagliderOG1.MetadataError, and the supporting modules tools, plotters, vocabularies and contributors.

Modules

  • __init__.py — the public verbs (read, convert, write, report, enrich, process, process_missions), re-exported from the modules below.

  • readers.py — read basestation files from a server or a local directory.

  • _convert.py — convert orchestrates mapping, standardisation, concat and the single post-concat dtype pass; process / process_missions run the pipeline from a configuration. Private: not imported directly.

  • writers.py — write OG1 files and enrich a written file’s globals.

  • mission.py — the mission.yaml schema: load, check.

  • tools.py — user-facing utilities.

  • vocabularies.py — vocabulary and mapping tables (the defaults; see Packaged defaults and your local tables).

  • plotters.py — plotting. contributors.py — contributor/institution record handling.

  • reports/ — the HTML conversion page (report) and the reader behind it.

  • cli/ — the seagliderOG1 command, one module per verb.

  • config/*.yaml — the OG1 mappings and vocabularies (see Packaged defaults and your local tables).

seagliderOG1.convert(list_of_datasets: Sequence[Dataset], mission: str | PathLike | Mapping[str, object] | None = None, *, contributors: Sequence[dict] | None = None, institutions: Sequence[dict] | None = None, platform: dict[str, object] | None = None, deployment: dict[str, object] | None = None, deployment_information: dict[str, object] | None = None, global_attributes: dict[str, object] | None = None, sensors: Mapping[str, Mapping[str, object]] | None = None, mode: str | None = None, record: dict | None = None) → Dataset[source]

Convert Seaglider basestation datasets to OG1 format.

Maps and standardises each dataset, concatenates them on a shared time axis, sorts by time, and applies platform, deployment and contributor attributes.

Parameters:

  • list_of_datasets (sequence of xarray.Dataset) – A list of xarray datasets in basestation format. The datasets are concatenated and sorted by time, so the input order does not matter: start_date, TRAJECTORY and the output id are seeded from the earliest measurement time and so always agree with time_coverage_start.

  • mission (str or os.PathLike or collections.abc.Mapping, optional) – A mission.yaml path or an already-loaded mapping (from seagliderOG1.mission.load()). Its platform, the three global-attribute sections (merged into deployment), global_attributes, sensors, contributors, institutions and mode are used; the raw_dir / output_dir / dives keys are ignored (convert works on datasets already read). An explicit keyword below overrides the mission value — including an explicit empty mapping (platform={}), which overrides the mission’s block with nothing rather than falling back to it. Default is None.

  • contributors (sequence of dict, optional) – Contributor records (name, role and optional email, orcid) merged with those already on the files. When None, contributors come from the files’ own attributes; no package default is applied. Default is None.

  • institutions (sequence of dict, optional) – Institution records (name, role and optional id) merged with those on the files and resolved against the EDMO registry. Default is None.

  • platform (dict of str to object, optional) – Platform fields from the mission config (PLATFORM_SERIAL_NUMBER, PLATFORM_MODEL, PLATFORM_MAKER, PLATFORM_DEPTH_RATING, GLIDER_FIRMWARE_VERSION, LANDSTATION_VERSION, WMO_IDENTIFIER, platform_model_vocabulary). Config values override file-derived ones. Default is None.

  • deployment (dict of str to object, optional) – The deployment-identity globals from the mission config deployment block (id, program, license, doi, site, …). Written as global attributes; a value for id (derived) or comment (kept from the basestation files when they carry one) overrides it with a warning. Nulls skipped. Default is None.

  • deployment_information (dict of str to object, optional) – The cruise-level deployment position and time from the mission config deployment_information block (DEPLOYMENT_TIME, DEPLOYMENT_LATITUDE, DEPLOYMENT_LONGITUDE). When given they set the OG1 DEPLOYMENT_* variables; otherwise they are derived from the first in-water fix. DEPLOYMENT_TIME after the first data sample warns. Default is None.

  • global_attributes (dict of str to object, optional) – Global attributes written verbatim into the output (nulls skipped). A key that collides with a converter-derived global, or with a key that has a structured home in deployment, raises. Default is None.

  • sensors (collections.abc.Mapping, optional) – Corrections to the basestation sensor records, from the mission config sensors: block: sensor key (a name in the instrument global) to {"serial_number": ..., "calibration_date": ...}. A corrected serial names the SENSOR_* variable; the sensor’s comment records the value it replaced. Default is None.

  • mode (str or None, optional) – Data mode, "realtime" or "delayed". Sets the id suffix (R or delayed) and so the output filename, per the OG1 manual, which defines no separate data-mode attribute. Default is None: the mission’s mode if it has one, else "realtime". An explicit value (including "realtime") always wins over the mission’s.

  • record (dict, optional) – When given, filled in place with what the output file cannot record about its own conversion: inputs (one {"path", "bytes", "dive"} per input file) and presence (which dives each variable is present and valid in). Pass it to writers.write(..., record=record) to write it beside the file. Default is None.

Returns:

The concatenated and processed dataset in OG1 format.

Return type:

xarray.Dataset

Raises:

  • MetadataError – If an OG1-mandatory global attribute is absent after all metadata sources are merged (a converter problem: the mandatory set is derived or constant).

  • ValueError – If global_attributes sets a converter-derived or deployment-home key, if deployment has an unknown key, if no datasets are valid, or if mode is not "delayed"/"realtime".

seagliderOG1.write(ds: Dataset, path: str | Path, *, overwrite: bool = False, record: dict | None = None) → Path[source]

Write the dataset to a NetCDF file with lossless compression.

Every non-scalar numeric variable, coordinates included, is written with zlib at level 4 and the shuffle filter. Attributes are checked before anything is written: one netCDF cannot store is refused by name, never converted to text. The input dataset is copied first, so the caller’s dataset is not modified.

Parameters:

  • ds (xr.Dataset) – Dataset to save.

  • path (str or pathlib.Path) – Output NetCDF file path.

  • overwrite (bool, optional) – If True, an existing file will be deleted and replaced. If False, a FileExistsError is raised when the file exists.

  • record (dict, optional) – The conversion record (as filled by convert(record=...)) to write beside the file as <stem>_conversion.json (conversion_path()), bound to it by the dataset’s id and tracking_id; a record already there is replaced. Nothing from it is written into the NetCDF file. Default is None (no record).

Returns:

The path written.

Return type:

pathlib.Path

Raises:

  • FileExistsError – If path exists and overwrite is False.

  • ValueError – If the dataset carries a None-valued attribute.

  • TypeError – If an attribute (global or on a variable) has a type netCDF cannot store, such as a dict or a bool; the message names each one. Nothing is written or removed.

seagliderOG1.enrich(path: str | Path, *, mission: str | Path | Mapping[str, object] | None = None, deployment: Mapping[str, object] | None = None, global_attributes: Mapping[str, object] | None = None, doi: str | None = None) → Path[source]

Set global attributes on a written OG1 file without converting again.

For metadata that exists only after the file is written — a DOI assigned on publication — or a corrected global-attribute value. Only global attributes change (edited in place; variables are not rewritten). The file gets date_modified set to now, a history line naming the keys, and a new tracking_id; date_created is kept. Every value is checked before the file is opened for writing, so a refused value leaves the file as it was. Replacing a different value already in the file warns with both values. The conversion record beside the file is rebound to the new tracking_id and SHA-256.

Parameters:

  • path (str or pathlib.Path) – The OG1 netCDF file.

  • mission (str or os.PathLike or collections.abc.Mapping, optional) – A mission.yaml path or loaded mapping; only its three global-attribute sections and global_attributes are used (merged into deployment and global_attributes below). The platform: block and other keys are ignored — enrich edits globals only. Default is None.

  • deployment (collections.abc.Mapping, optional) – Deployment-identity globals to set (as in seagliderOG1.convert()); null values are skipped. Overrides the mission’s merged sections. Default is None.

  • global_attributes (collections.abc.Mapping, optional) – global_attributes: keys to set. Overrides the mission’s. Default is None.

  • doi (str, optional) – The DOI, written as the doi global (wins over deployment["doi"]).

Returns:

The enriched file.

Return type:

pathlib.Path

Raises:

  • ValueError – If nothing is given to set; a key is one the converter owns or that belongs in the other block; a value is not text, a number or a date; a key is one enrich writes itself (date_modified, history, tracking_id, draft) or a conversion_* record; or deployment["id"] differs from the file’s id (the file name and the conversion record are bound to it: convert again to change it).

  • FileNotFoundError – If path does not exist.

The path of the written OG1 file.

pathlib.Path

Raises:

mission

Mission-configuration schema, loader and validator.

The mission configuration (mission.yaml) lives outside the installed package so that platform, contributor and global-attribute metadata belong to the user rather than to seagliderOG1. This module holds the known keys, the validation checks, and the two public entry points a caller needs:

  • load() reads a mission.yaml (or an already-loaded mapping), validates it, resolves raw_dir / output_dir relative to the file, and returns the configuration with the file’s own keys (the three global-attribute sections left unmerged).

  • check() returns the list of validation issues without raising, for the validate verb to print.

It is the single place that parses a mission configuration. The commented template that init writes, and the printing of issues, stay in the CLI (cli/_mission.py), which imports the schema tables from here.

Kept import-light on purpose (module-level imports are the standard library and yaml only); readers, vocabularies and contributors are imported inside the functions that need them, so building the CLI parser and --help do not pull in xarray or the packaged-YAML reads.

vocabularies

Vocabularies and mappings for OG1 format conversion.

This module defines the vocabulary mappings, unit conversions, and attribute configurations used to convert Seaglider basestation files to OG1 format. It loads YAML configuration files and defines various dictionaries used throughout the conversion process.

Key Components:

  • Variable name mappings from basestation to OG1 format

  • Unit conversion factors and formatting rules

  • Global attribute definitions and ordering

  • Variables to include/exclude during conversion

  • Dimension renaming mappings

Configuration Files:

  • OG1_variable_names.yaml: Variable name mappings

  • OG1_unit_corrections.yaml: Basestation units labels that are wrong for the values

  • OG1_sensor_names.yaml: Sensor keys to OG1_sensor_attributes.yaml titles

  • OG1_variable_attributes.yaml: Variable attribute vocabularies

  • OG1_sensor_attributes.yaml: Sensor attribute definitions

  • OG1_global_attributes.yaml: Global attribute configurations

Notes

This module is primarily data-driven and loads most configuration from YAML files in the config/ directory. The YAML-based approach allows easy modification of OG1 format requirements without code changes.

contributors

Contributor and institution attributes for OG1, as comma-aligned lists.

OG1 records contributors as parallel comma-separated attributes — contributor_name, contributor_email, contributor_id, contributor_role and contributor_role_vocabulary — one slot per person, empty slots preserved so the lists stay aligned (three people with one email give "a@x, , c@z"). Institutions are a separate parallel set (contributing_institutions and its _role, _vocabulary and _role_vocabulary).

This module parses those attributes into records and formats records back, without dropping interior empties, deduping within a field, or rewriting commas inside a value. One role per slot: a person with two roles is listed twice.
