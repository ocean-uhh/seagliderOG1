seagliderOG1 API

At a glance, in pipeline order:

  • convert.process_mission — the whole pipeline for one mission: read, convert, write (and optionally the HTML conversion page). The calls below are its steps.

  • readers.read_mission — read a mission’s basestation files into a list of datasets.

  • convert.to_og1 — convert that list into one OG1 dataset.

  • convert.keep_variables — optionally subset to a science-variable allow-list.

  • writers.write — write the OG1 dataset to netCDF.

  • tools.add_depth / add_phase / add_profile_number — add derived variables.

  • plotters.plot_* / plotters.show_* — quick-look figures and text tables.

  • vocabularies and contributors — the metadata vocabularies and contributor/institution records.

convert

Convert Seaglider basestation files to OG1 format.

This module provides the core functionality for converting Seaglider basestation NetCDF files into OG1 (Ocean Gliders 1) format. It handles data processing, variable renaming, attribute assignments, and dataset standardization.

exception seagliderOG1.convert.MetadataError[source]

An OG1-mandatory global attribute is missing from the converted dataset.

Raised by seagliderOG1.convert.to_og1() after the three metadata sources (data-derived, package constants, mission config) are merged, when a mandatory global attribute is absent or holds a placeholder. Subclasses ValueError so existing except ValueError handlers still catch it.

seagliderOG1.convert.conversion_ledger(ds: Dataset) → dict[source]

Return what the conversion recorded in a file, read from the file alone.

Parses the conversion-ledger globals and the per-scalar storage once, so a caller (the inspect text view, the HTML page) does not re-decode the JSON or re-walk the variables. Everything returned is reconstructable from the file; nothing is read from conversion-time state.

Parameters:

ds (xarray.Dataset) – An OG1 dataset written by to_og1().

Returns:

Keys dimensions (dimension to {"fate", "variables"}), derived (derived-variable name to its list of source basestation names), dropped (list of names), removed (list of names), input_variable_count (int), attribute_sources (category to names), history (str) and scalar_parameters (name to {"storage", "original_name", "units"}, plus "dives" and "values" for a per-dive scalar).

Return type:

dict

Raises:

MetadataError – If ds predates the ledger (no conversion_dimensions), or a per-dive scalar’s value is not the per-dive JSON this package writes.

seagliderOG1.convert.process_mission(source: str | PathLike, output_dir: str | PathLike, *, dives: tuple[int, int] | None = None, contributors: Sequence[dict] | None = None, institutions: Sequence[dict] | None = None, platform: dict[str, object] | None = None, deployment: dict[str, object] | None = None, global_attributes: dict[str, object] | None = None, mode: str = 'delayed', keep_variables: Sequence[str] | None = None, repair: bool = False, overwrite: bool = False, report: bool = False) → Path[source]

Convert one Seaglider mission to an OG1 file: read, convert, subset, write.

The library form of seagliderOG1 process for a single mission: the CLI calls this once per selected mission. The file is written as <output_dir>/<id>.nc, where id is the converter-derived (or deployment-supplied) identifier.

Parameters:

  • source (str or os.PathLike) – One mission directory holding basestation files (pSSSDDDD*.nc). A root of SN/DATE missions is refused; select one with seagliderOG1.readers.discover_missions() and pass its path.

  • output_dir (str or os.PathLike) – Directory the OG1 file is written to; created if missing.

  • dives (tuple of (int, int), optional) – First and last dive to convert, inclusive. Default is None (every dive).

  • contributors (sequence of dict, optional) – Contributor records, as for to_og1(). Default is None.

  • institutions (sequence of dict, optional) – Institution records, as for to_og1(). Default is None.

  • platform (dict of str to object, optional) – Platform fields, as for to_og1(). Default is None.

  • deployment (dict of str to object, optional) – Deployment-identity globals, as for to_og1(). Default is None.

  • global_attributes (dict of str to object, optional) – Global attributes written verbatim, as for to_og1(). Default is None.

  • mode (str, optional) – Data mode, "delayed" (default) or "realtime"; sets the id suffix and so the filename. Default is “delayed”.

  • keep_variables (sequence of str, optional) – Science variables to keep (see keep_variables()); OG1-mandatory variables always survive. Default is None (keep all).

  • repair (bool, optional) – Repair basestation time metadata before loading; this rewrites files in the source tree (see seagliderOG1.readers.read_mission()). Default is False.

  • overwrite (bool, optional) – Replace an existing output file (and, with report, the page). Default is False.

  • report (bool, optional) – Also write the HTML conversion page (seagliderOG1.reports.conversion.render_conversion()) beside the file as <output_dir>/<id>_conversion.html. Default is False.

Returns:

The path of the written OG1 file.

Return type:

pathlib.Path

Raises:

  • ValueError – If source is not a directory, holds no basestation files, or is a root of SN/DATE missions; or as raised by to_og1().

  • FileExistsError – If the output file (or, with report, the page) exists and overwrite is False; nothing is written. filename is the existing path. The conversion has already run by then: the file name derives from the converted id.

  • MetadataError – As raised by to_og1().

Notes

With report=True the page is rendered from the written file. If the render fails, the OG1 file stays written and the error propagates.

See also

to_og1

The conversion step alone, on datasets already read.

seagliderOG1.convert.to_og1(list_of_datasets: Sequence[Dataset], *, contributors: Sequence[dict] | None = None, institutions: Sequence[dict] | None = None, platform: dict[str, object] | None = None, deployment: dict[str, object] | None = None, global_attributes: dict[str, object] | None = None, mode: str = 'delayed') → Dataset[source]

Convert Seaglider basestation datasets to OG1 format.

Maps and standardises each dataset, concatenates them on a shared time axis, sorts by time, and applies platform, deployment and contributor attributes.

Parameters:

  • list_of_datasets (sequence of xarray.Dataset) – A list of xarray datasets in basestation format. The datasets are concatenated and sorted by time, so the input order does not matter: start_date, TRAJECTORY and the output id are seeded from the earliest measurement time and so always agree with time_coverage_start.

  • contributors (sequence of dict, optional) – Contributor records (name, role and optional email, orcid) merged with those already on the files. When None, contributors come from the files’ own attributes; no package default is applied. Default is None.

  • institutions (sequence of dict, optional) – Institution records (name, role and optional id) merged with those on the files and resolved against the EDMO registry. Default is None.

  • platform (dict of str to object, optional) – Platform fields from the mission config (PLATFORM_SERIAL_NUMBER, PLATFORM_MODEL, PLATFORM_MAKER, PLATFORM_DEPTH_RATING, GLIDER_FIRMWARE_VERSION, LANDSTATION_VERSION, WMO_IDENTIFIER, platform_model_vocabulary). Config values override file-derived ones. Default is None.

  • deployment (dict of str to object, optional) – The deployment-identity globals from the mission config deployment block (id, program, license, doi, site, …). Written as global attributes; a value for id or comment overrides the converter-derived default with a warning. Nulls skipped. Default is None.

  • global_attributes (dict of str to object, optional) – Global attributes written verbatim into the output (nulls skipped). A key that collides with a converter-derived global, or with a key that has a structured home in deployment, raises. Default is None.

  • mode (str, optional) – Data mode, "delayed" (default) or "realtime". Sets the id suffix (delayed or R) and so the output filename, per the OG1 manual, which defines no separate data-mode attribute. Default is “delayed”.

Returns:

The concatenated and processed dataset in OG1 format.

Return type:

xarray.Dataset

Raises:

  • MetadataError – If an OG1-mandatory global attribute is absent after all metadata sources are merged (a converter problem: the mandatory set is derived or constant).

  • ValueError – If global_attributes sets a converter-derived or deployment-home key, if deployment has an unknown key, if no datasets are valid, or if mode is not "delayed"/"realtime".

vocabularies

Vocabularies and mappings for OG1 format conversion.

This module defines the vocabulary mappings, unit conversions, and attribute configurations used to convert Seaglider basestation files to OG1 format. It loads YAML configuration files and defines various dictionaries used throughout the conversion process.

Key Components:

  • Variable name mappings from basestation to OG1 format

  • Unit conversion factors and formatting rules

  • Global attribute definitions and ordering

  • Variables to include/exclude during conversion

  • Dimension renaming mappings

Configuration Files:

  • OG1_variable_names.yaml: Variable name mappings

  • OG1_variable_attributes.yaml: Variable attribute vocabularies

  • OG1_sensor_attributes.yaml: Sensor attribute definitions

  • OG1_global_attributes.yaml: Global attribute configurations

Notes

This module is primarily data-driven and loads most configuration from YAML files in the config/ directory. The YAML-based approach allows easy modification of OG1 format requirements without code changes.

contributors

Contributor and institution attributes for OG1, as comma-aligned lists.

OG1 records contributors as parallel comma-separated attributes — contributor_name, contributor_email, contributor_id, contributor_role and contributor_role_vocabulary — one slot per person, empty slots preserved so the lists stay aligned (three people with one email give "a@x, , c@z"). Institutions are a separate parallel set (contributing_institutions and its _role, _vocabulary and _role_vocabulary).

This module parses those attributes into records and formats records back, without dropping interior empties, deduping within a field, or rewriting commas inside a value. One role per slot: a person with two roles is listed twice.

Write the dataset to a NetCDF file with lossless compression.

Every non-scalar numeric variable, coordinates included, is written with zlib at level 4 and the shuffle filter. If a TypeError occurs due to invalid attribute values, converts the invalid attributes to strings and retries the save. The input dataset is copied first, so the caller’s dataset is not modified.

seagliderOG1.tools.add_profile_number(ds: Dataset, ds1: Dataset) → Dataset[source]

Assign profile numbers to measurements based on dive phases (down/up casts).

This function separates each dive into two profiles: descent (down cast) and ascent (up cast) phases. The dive is split at the maximum pressure point, with the descent phase getting the dive number and ascent getting dive + 0.5. Profile numbers are then calculated as 2 * DIVE_NUMBER - 1.
